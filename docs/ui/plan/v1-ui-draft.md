# v1 UI 草稿（用户提供，2026-11-06）

*设计输入，不是规格书。只记录用户给的布局/交互意图；数值与实现以代码与 `design/` 为准。*

## 布局

```text
╭────────────┬───────────────────────────────┬──────────────┐
│ 源          │  [窗口工具栏：对比 · …… · 提交]     │ 调整          │
│ ─────────  │                               │ ───────────  │
│ 服务器 A     │                               │ 直方图（固定） │
│  ▸ 文件夹1      │          画 布                 │              │
│  ▸ 文件夹2      │                                 │ 曝光   ───○─ │
│            │                               │ 对比   ──○── │
│ ─────────  │  ─────────────────────────────  │ 高光   ○──── │
│ ● 已连接     │ 胶片条 ▮▮▮▮▮▮▮▮▮▮            │           │
│ ⚙ 设置       │                               │              │
╰────────────┴───────────────────────────────┴──────────────╯
```

- **两个栏位，不要三栏**：`NavigationSplitView(sidebar:detail:)` + 在 detail 上挂 `.inspector`。inspector 在 horizontal regular 下是尾随列，compact 下自动变 sheet；宽度用 `inspectorColumnWidth(min:ideal:max:)`，不写死。
- 左栏装「目录/集合」（有层级，会变长）；底部胶片条是「当前集合」（扁平、有序）。**两者不重复**。
- 胶片条带标记小圆点，显示提交状态（已提交/未提交/提交中/提交失败）。
- 设置在 `⚙` 菜单里，用 sheet 呈现。

## 工具栏

窗口工具栏 = 全局动作；自动获得玻璃材质，窄窗自动折叠成溢出菜单。最终形态：

```text
文件名 ▸ 未提交        ...   [↩▾] [对比] [更多▾] [提交]
↑ 导航标题区                    ↑ 历史    ↑ 假色、复制粘贴  ↑ 主操作
```

| 功能 | 说明 |
|---|---|
| 提交 | 主操作（强调样式），工具栏最右，`.primaryAction` |
| 对比 | 按住临时，轻点锁定 |
| 撤销 / 重做 | 调整历史，合并为一个菜单按钮 |
| 复制 / 粘贴调整 | 溢出菜单 + 上下文菜单，条件性出现 |
| 假色 | 客户端渲染，收进菜单 |

## 状态条

画布列底部、胶片条之上：recipe 提交状态、图片基本信息、当前显示器 HDR headroom。示例：

```text
2560×1700（预览）· Display P3 · 16-bit             HDR 4.2× / 16× · 67%
```

设置里可调整「图片基本信息」显示哪几项（色域、色深、EXIF 如相机型号/拍摄日期等）。

## 检视器

右栏是 **recipe 的可视化**：recipe 是有序操作栈。

- 每一项 = 一个操作（曝光、曲线、裁剪……），带启用/停用开关和数值显示；
- 滑杆只是操作内部的参数编辑器；
- 顺序 = 数据本身的顺序。

QoL 细节：

- 直方图固定在顶部，不随滚动消失；
- 每个参数双击复位；
- 参数值可点击进入数值输入；
- 整块 section 可折叠，折叠状态记在 `@SceneStorage`。

## 画布背景色

固定 3 档：中性 18% 灰 / 白 / 黑，在设置中调整。

## 与当前 wire/model 的映射（Lead 注，不是草稿）

| 草稿元素 | 当前能力 | v1 处理 |
|---|---|---|
| 两栏 + `.inspector` | SwiftUI 原生 | 直接做 |
| 工具栏提交 / 对比 / 假色 | `JudgeModel.postRecipe` / `beginCompare` / `JudgeRenderMode.overlay` 已存在 | 直接接 |
| 撤销/重做、复制/粘贴调整 | 模型没有调整历史 | 先做 view-local 历史（不写第二个状态机） |
| 胶片条 + 提交状态 | `items` + `receipt`/`isDirty`/`phase` | 可直接映射 |
| 状态条 | item 尺寸 + `PreviewMetadata`（P3/16-bit）+ `displayHeadroom` | 可接；显示项设置要新增 |
| 检视器操作栈 | **recipe schema 0 有 `hdr.{start,lift_stops,transition,headroom_cap}`**；没有曝光/曲线/裁剪 | 已定：3 个 slider + cap stops picker（0.5–3），不扩 recipe |
| 直方图 | base 已解码为 `LinearImage` | UI 侧纯函数可行（不碰 engine） |
| 左栏目录树（服务器/文件夹层级） | 服务端是**单 `--batch` 目录、扁平 items、不递归** | **待拍板**：v1 只做单批次的源节点，还是改 server/wire（超出 v1 冻结） |
| 画布背景 3 档 | 纯 UI | 直接做 |
| 设置项（图片信息/背景） | 现有 settings 只有 host/port/token | 新增客户端设置，不碰 wire |
