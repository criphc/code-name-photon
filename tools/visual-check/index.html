How to judge. Lit room, ~50 % brightness, True Tone / Night Shift off. The HDR file should make the sun glints and specular highlights brighter than white, while sky, road and everything else stay identical to the SDR reference. If the two look exactly the same → fail. If the whole picture is brighter or washed out → fail. Ask “which one looks like the print?”, never “which one is HDR?”.

This page is folder-driven: it fetches /manifest.json and renders whatever is in the served --root folder. Put the delivery there using this convention:

  • {stem}-hdr-{profile}.heic (e.g. 10-half-rgb; legacy {stem}-hdr.heic also recognised) — the delivered gain-map HEIC (must render HDR in Photos/Safari)
  • {stem}-sdr.heic — the map-stripped fallback copy (must look like the Capture One export)
  • other .heic/.heif/.jpg/.jpeg/.png — look references, not pixel-for-pixel targets
  • {stem}.report.json — optional delivery report (verdict, checks, measured numbers)
  • {stem}.recipe.json — optional recipe that produced the delivery

Then start the server pointed at that folder:

python3 tools/visual-check/serve.py --root DIR

1 — Delivered HDR

These are the files Photos and Safari must render with the intended HDR: only the authored highlights go brighter than white. A viewer that shows the same image as section 2 is rendering the SDR base (or the gain map was not applied).

2 — SDR fallback

The map-stripped copy: this is what non-HDR viewers see and it must look like the Capture One export. Compare section 1 against this — only the authored highlights should differ.

3 — Look references

“Which looks like the print?” targets, not files to match pixel-for-pixel. Judge the highlight roll-off and naturalness of the delivered file against these references; do not copy their overall colour or contrast.

4 — Delivery report

This page is a viewer, not a measurement: HDR rendering depends on Safari, iPadOS, the display and its HDR settings. Objective facts come from tools/verify-heic and the delivery report. Never use sips to judge HDR — it silently strips the gain map.
